# 小批量标签拼版 Web 工具

输入纸张尺寸、页边距、多种标签的宽高与份数、裁切间距及是否允许旋转，
自动在每张纸上安排**互不重叠**的位置；放不下自动续页，并显示每种标签
实际排入数量。预览与可下载打印的 SVG 使用**同一套毫米坐标**，页边距与
间距在导出中完全一致；如配置了打印位置校准，仅下载 / 打印的 SVG 会
按逆变换补偿标签内容，预览与 `/api/layout` 的坐标、数量保持原样。

支持**复用首张已贴过标签的纸张**：为第一张纸配置若干「占用区」
（左上角 x/y、宽、高，单位毫米），排版时作为障碍避让，新标签与其
保持设定的裁切间距；第一页放不下的份数自动续到后续空白页。预览中
占用区以灰色显示，下载 / 打印的 SVG 只包含新标签。

支持**打印位置校准**：打印一张含横、纵两组基准刻线的测试页，
录入各刻线的设计坐标与纸上实测坐标，自动按最小二乘求出 X / Y 方向
的线性走纸误差（缩放 + 偏移）；下载及打印 SVG 时对标签轮廓、
裁切线和标注做逆变换补偿。常规页面预览与 `/api/layout` 的坐标、
数量始终保持原始设计值，不参与补偿。

技术栈：Python 3.11 + FastAPI + 原生 HTML / CSS / JavaScript（无前端构建）。

## 一条命令启动

需要 Docker 与 Docker Compose（v2，`docker compose` 子命令），
无需其他配置、不依赖数据库：

```bash
docker compose up --build
```

启动后浏览器访问：

- **http://localhost:8000**

必要配置：

- 服务在容器内监听 **8000 端口**，`docker-compose.yml` 已映射到宿主机
  的 `8000`；如端口被占用，把其中 `"8000:8000"` 左侧改为空闲端口
  （如 `"8080:8000"`），再访问 `http://localhost:8080`。
- 无需环境变量、无需挂载卷；镜像构建时安装依赖，容器启动时自动执行
  排版 / SVG / 校准自检。

停止：`Ctrl+C`，或在另一个终端执行 `docker compose down`。

> 容器启动时会自动执行：安装依赖 → 初始化自检（排版与 SVG 生成冒烟测试）
> → 启动 uvicorn。

## 功能说明

- **纸张**：内置 A4 / A5 / Letter 纵横预设，也可自定义任意毫米尺寸。
- **页边距**：上 / 右 / 下 / 左独立设置。
- **裁切间距**：水平、垂直分别设置；间距只出现在相邻标签之间，
  纸边不留多余半格。
- **多种标签**：任意行数，每行设置名称、宽 (mm)、高 (mm)、份数、
  是否允许旋转 90°。
- **首张纸占用区（复用已贴纸的纸）**：
  - 在「首张纸占用区」中添加任意多个矩形，填写**左上角 X、左上角 Y、
    宽、高**（均为毫米，原点在纸张左上角），可随时编辑或删除；
  - 占用区必须完全在纸张范围内，越界（含负坐标、右边/下边超出纸张）
    会在前端与接口处给出明确错误，不生成排版；
  - 新标签把占用区当作障碍，无论从左、右、上、下接近，都至少保持
    设定的水平 / 垂直裁切间距；多个占用区可以重叠；
  - 第一页排不下的份数自动续到后续**空白页**，统计不丢失、不重复；
  - 占用区完全落在页边距区域内时不报错，仅提示“不影响排版”。
- **自动排版**：天际线（skyline）左下角装箱，标签位置互不重叠；
  当前页放不下自动续页；允许旋转时会尝试 90° 方向。
- **排入统计**：表格列出每种标签的需求数、实际排入数、旋转数、未排入数；
  单张标签超过可排区域时给出明确提示。
- **预览 / 导出同源**：浏览器预览和下载的 SVG 都由后端
  `POST /api/svg` 基于同一份排版结果生成，单位均为毫米。预览第一页以
  **灰色斜纹**绘制占用区；下载 / 打印的 SVG **只含新标签**，
  两者标签坐标完全一致。
- **导出**：支持「下载本页 SVG」「下载全部页」，以及按纸张精确尺寸
  排版的「打印全部页」（`@page size` 等于纸张毫米尺寸，无边距）。
- **打印位置校准（仅影响下载 / 打印，不影响预览与排版坐标）**：
  1. 点击「打印校准测试页」（或先下载测试页 SVG），打印对话框中
     **务必选择 100% 比例、关闭“适应页面/缩小到可打印区域”**；
  2. 测试页顶部蓝色横轨上有 3 条**纵向基准刻线**，沿轨量取每条线到
     **纸左边缘**的距离，即 X 方向实测坐标；左侧橙色竖轨上有 3 条
     **横向基准刻线**，沿轨量取每条线到**纸上边缘**的距离，即 Y 方向
     实测坐标（设计坐标已印在每条刻线旁，并已预填到录入表）；
  3. 点击「计算并应用校准」：后端对每个方向做最小二乘拟合
     `实测 = k·设计 + b`（`k` 为走纸比例、`b` 为零位偏移），显示
     X / Y 的比例与偏移，并逐页检查补偿结果；
  4. 勾选工具栏「导出时应用校准补偿」后，下载 / 打印的 SVG 会把标签
     轮廓、裁切角线、标注整体按逆变换
     `x绘 = (x − b) / k`（Y 同理）放置，打印结果即落回设计位置；
     纸张边框、页边距参考线、页码不补偿。
  - 某方向留空则该方向不修正；只填一条刻线按纯平移（`k=1`）处理；
  - 刻线行数可自行增减，不局限于默认的 3 条。
  - **以下情况会阻止校准导出并给出中文原因**：
    - **基准点重合**：同一方向两条刻线设计坐标相同，无法求比例；
    - **实测顺序颠倒**：实测坐标没有随设计坐标同向增大（录入或
      读数方向错误，含全部读数相同）；
    - **补偿超出纸张**：逆变换后标签轮廓或裁切角线越过纸边
      （提示发生在第几页、哪个方向、到达的坐标）。

## 接口

| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| GET  | `/health` | 健康检查 |
| POST | `/api/layout` | 提交参数（含首张纸 `occupied_zones`），返回分页排版结果（毫米坐标）；**不受校准影响** |
| POST | `/api/svg` | 提交参数 + 页码 + 显示开关 + 可选 `calibration`，返回该页 SVG；`calibration` 非空时标签内容按逆变换补偿 |
| POST | `/api/calibration/marks` | 按纸张尺寸返回测试页默认刻线设计坐标 |
| GET  | `/api/calibration/test-page?width=&height=` | 下载含横、纵两组基准刻线的校准测试页 SVG |
| POST | `/api/calibration/validate` | 拟合 X / Y 走纸误差并逐页检查补偿是否越界，返回比例与偏移 |

`/api/svg` 在服务端重新计算同一份排版，保证导出坐标与预览一致。
其 `show_occupied` 开关仅预览时为 `true`（第一页灰色绘制占用区）；
下载 / 打印时为 `false`，SVG 中只包含新标签。`calibration` 仅在
下载 / 打印时传入（常规预览传 `null`），且不改变 `/api/layout`
返回的任何坐标与数量。三种非法校准（基准点重合、实测顺序颠倒、
补偿超出纸张）均返回 HTTP 400 及明确中文原因。
API 文档（Swagger）：http://localhost:8000/docs

### 请求示例

```json
{
  "page_width": 210,
  "page_height": 297,
  "margin_top": 8,
  "margin_right": 8,
  "margin_bottom": 8,
  "margin_left": 8,
  "gap_x": 2,
  "gap_y": 2,
  "labels": [
    {"name": "品名标签", "width": 60, "height": 30, "count": 20, "allow_rotate": true},
    {"name": "箱贴", "width": 100, "height": 70, "count": 6, "allow_rotate": false}
  ],
  "occupied_zones": [
    {"x": 48, "y": 48, "width": 100, "height": 100}
  ]
}
```

`occupied_zones` 为可选数组，仅作用于第一页；每项的 `x` / `y` 为
占用区左上角相对纸张左上角的坐标，`width` / `height` 为其尺寸。
越界（`x + width > page_width`、`y + height > page_height` 或坐标为负）
返回 HTTP 400 及明确中文错误，例如：

```text
占用区 1越界：x(120.0) + 宽(100.0) = 220.0mm 超过纸张宽度 210.0mm。
```

### 打印位置校准参数（仅 `/api/svg` 与 `/api/calibration/validate`）

`calibration` 为可选对象，包含 X / Y 两组刻线，每组若干
`{designed, measured}`（设计坐标与纸上实测坐标，毫米）：

```json
{
  "page": 1,
  "show_margins": true,
  "show_annotations": true,
  "show_occupied": false,
  "params": { "page_width": 210, "page_height": 297,
              "labels": [{"width": 60, "height": 30, "count": 20}] },
  "calibration": {
    "x_points": [
      {"designed": 20, "measured": 21.5},
      {"designed": 105, "measured": 106.7},
      {"designed": 190, "measured": 191.9}
    ],
    "y_points": [
      {"designed": 20, "measured": 19.4},
      {"designed": 148.5, "measured": 147.3},
      {"designed": 277, "measured": 275.6}
    ]
  }
}
```

`/api/calibration/validate` 的响应给出拟合结果：

```json
{"x":{"used":3,"scale":1.002353,"offset":1.453,"scale_percent":100.2353,"identity":false},
 "y":{"used":3,"scale":0.996887,"offset":-0.604,"scale_percent":99.6887,"identity":false},
 "all_pages_fit":true,"page_count":1}
```

基准点重合、实测顺序颠倒（`k <= 0`）、补偿超出纸张时返回 HTTP 400：

```text
X（纵向刻线）方向实测顺序颠倒：设计坐标递增（20 → 190）但实测坐标为 90、30，
实测坐标必须随设计坐标同向增大，请核对读数方向与录入顺序。
```

## 本地开发（不使用 Docker）

```bash
pip install -r requirements.txt
python -m app.bootstrap          # 可选：初始化自检
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

## 目录结构

```
.
├── app/
│   ├── main.py        # FastAPI 路由（排版 / SVG / 校准接口）

│   ├── layout.py      # 天际线拼版算法

│   ├── style.css
│   └── app.js
├── docker/entrypoint.sh
├── Dockerfile
├── docker-compose.yml
└── requirements.txt
```
